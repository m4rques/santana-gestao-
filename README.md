# santana-gestao-
Sistema de gestão para concessionária de veículos — Projeto acadêmico UCSAL
Situação atual: Somente o front-end está pronto. O back-end em Java e o banco de dados PostgreSQL ainda serão adicionados.

Telas: Login, cadastro de clientes e veículos, busca de veículos, contrato de venda e relatórios.

Tecnologias: HTML, CSS e JavaScript. Em breve: Java e PostgreSQL.
